# WEBSSON

WEBSSON d.o.o. is a software company in Pula, Croatia. We make two products.

**[Uppcoder](https://portal.uppcoder.com/?utm_source=github&utm_medium=org-profile)** is a cloud platform for building and running apps: your stack and your editor in the browser, with a live HTTPS address. It includes:

- an [AI app builder](https://portal.uppcoder.com/ai-builder?utm_source=github&utm_medium=org-profile) that turns a description into a running app with a real database;
- [Uppcoder for Education](https://portal.uppcoder.com/education?utm_source=github&utm_medium=org-profile): a ready coding lab for every student, assignments marked by tests, on its own or inside Moodle, Canvas, Blackboard or Brightspace over LTI 1.3. It works as a [GitHub Classroom alternative](https://portal.uppcoder.com/github-classroom-alternative?utm_source=github&utm_medium=org-profile), with a [step-by-step autograding guide](https://portal.uppcoder.com/guides/autograde-python-canvas-moodle?utm_source=github&utm_medium=org-profile);
- hackathon and enterprise workspaces.

The free plan (one app with its database) needs no card and has no time limit; the other plans are on the [pricing page](https://portal.uppcoder.com/pricing?utm_source=github&utm_medium=org-profile).

**[StreamGen](https://streamgen.io/?utm_source=github&utm_medium=org-profile)** lists every Streamlit and App Runtime app in a Snowflake account in one place, with owners, usage, costs and health checks, and lets analysts build new ones by describing them. It is a Snowflake Native App on the [Snowflake Marketplace](https://app.snowflake.com/marketplace/listing/GZSYZ1QF5MJ/streamgen-streamgen), with a [free 7-day trial key](https://streamgen.io/trial/?utm_source=github&utm_medium=org-profile) ([pricing](https://streamgen.io/pricing/?utm_source=github&utm_medium=org-profile), [features](https://streamgen.io/features/?utm_source=github&utm_medium=org-profile), [guides](https://streamgen.io/guides/?utm_source=github&utm_medium=org-profile)). On GitHub: [streamgen-io](https://github.com/streamgen-io).

## Repositories here

- [django-postgresql-starter](https://github.com/websson/django-postgresql-starter): a small Django project on PostgreSQL with the admin, ready to deploy from Git or run with docker compose Guide: [deploy Django with PostgreSQL for free](https://portal.uppcoder.com/guides/deploy-django-postgresql?utm_source=github&utm_medium=org-profile).
- [fastapi-postgresql-starter](https://github.com/websson/fastapi-postgresql-starter): a small FastAPI app on PostgreSQL, ready to deploy from Git or run with docker compose Guide: [deploy FastAPI with PostgreSQL for free](https://portal.uppcoder.com/guides/deploy-fastapi-postgresql?utm_source=github&utm_medium=org-profile).
- [python-autograded-assignment](https://github.com/websson/python-autograded-assignment): an example autograded Python assignment (starter code, public and hidden tests, a reference solution) in the layout Uppcoder imports.
- [java-autograded-assignment](https://github.com/websson/java-autograded-assignment): the same idea in Java, with JUnit 5 tests and a Maven build.
- [github-classroom-alternatives](https://github.com/websson/github-classroom-alternatives): what teachers can use now that GitHub Classroom has been retired, hosted, open source and Moodle options, each with its own sources and prices (ours included).
