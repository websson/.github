# WEBSSON

WEBSSON d.o.o. is a software company in Pula, Croatia. We make two products.

**[Uppcoder](https://portal.uppcoder.com/?utm_source=github&utm_medium=org-profile)** is a cloud platform for building and running apps: your stack and your editor in the browser, with a live HTTPS address. It includes:

- an [AI app builder](https://portal.uppcoder.com/ai-builder?utm_source=github&utm_medium=org-profile) that turns a description into a running app with a real database;
- [Uppcoder for Education](https://portal.uppcoder.com/education?utm_source=github&utm_medium=org-profile): a ready coding lab for every student, assignments marked by tests, on its own or inside Moodle, Canvas or Blackboard over LTI 1.3. It works as a [GitHub Classroom alternative](https://portal.uppcoder.com/github-classroom-alternative?utm_source=github&utm_medium=org-profile);
- hackathon and enterprise workspaces.

**[StreamGen](https://streamgen.io/?utm_source=github&utm_medium=org-profile)** lists every Snowflake app in a company in one place, with owners, usage, costs and health checks, and lets analysts build new ones by describing them.

## Repositories here

- [django-postgresql-starter](https://github.com/websson/django-postgresql-starter): a small Django project on PostgreSQL with the admin, ready to deploy from Git or run with docker compose.
- [fastapi-postgresql-starter](https://github.com/websson/fastapi-postgresql-starter): a small FastAPI app on PostgreSQL, ready to deploy from Git or run with docker compose.
- [python-autograded-assignment](https://github.com/websson/python-autograded-assignment): an example autograded Python assignment (starter code, public and hidden tests, a reference solution) in the layout Uppcoder imports.
- [java-autograded-assignment](https://github.com/websson/java-autograded-assignment): the same idea in Java, with JUnit 5 tests and a Maven build.
- [github-classroom-alternatives](https://github.com/websson/github-classroom-alternatives): what teachers can use now that GitHub Classroom has been retired, hosted, open source and Moodle options, each with its own sources and prices (ours included).
